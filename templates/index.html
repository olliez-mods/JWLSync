How It Works

JW Library can only back up and restore. JWLSync watches your Google Drive folder, merges the backups from all your devices (notes, highlights, tags, bookmarks) and leaves one up to date backup any device can restore.

  1. Back up into your folder's JW Library Save folder
  2. Wait a few seconds for the merge
  3. Restore from the merged file there

Restoring replaces what's on the device, so always back up first.
