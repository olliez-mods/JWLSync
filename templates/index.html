How it works

JW Library can only back up and restore. JWLSync watches a Google Drive folder, merges the backups from all your devices (notes, highlights, tags, bookmarks) and leaves one up to date backup any device can restore.

Back up into your folder's JW Library Save folder, wait a few seconds for the merge, then restore from the file there. Restoring replaces what's on the device, so always back up first.
