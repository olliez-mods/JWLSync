How To Use
  1. In JW Library, make a backup and save it into the JW Library Save folder in your Drive folder
  2. Wait about 10 seconds while JWLSync merges it with your other devices' backups
  3. JW Library Save now holds one file, the merged backup. Restore it in JW Library on any device
Always back up before you restore. Restoring replaces everything on the device, so anything changed since that device's last backup would be lost.
